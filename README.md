The embedded system consists of the following: ESP-WROOM-32 (38-Pin) CP2102, OLED Display I2C (4-Pin) 0.91 inches, DS3231 RTC, Digital Temperature Sensor DS18B20, Passive Buzzer(not used), MP3-TF-16P V3.0, Micro SD card, 4k ohm resistor for Temp sensor, Green LED, 1k ohm resistor for the green LED, 5 small buttons (2-Pin each), obviously wires, and finally 2 connected breadboards.

This project was created for the sake of learning, and out of interest in embedded systems.

Feel free to modify your own version of the code and improve on it for your own needs; I am, however, done with this project.
